# codeximage

基于 Electron、React 和 TypeScript 的独立桌面聊天原型，配套 Node.js Agnes 模型网关。非 OpenAI 官方产品，与 OpenAI 无隶属或背书关系；名称所涉及的商标属于各自所有者。

## 当前能力与边界

- 本地邮箱账号注册、登录，以及按账号隔离的本机 SQLite 工作区。
- 纯文字流式对话、停止、失败重试和本地聊天记录；所有界面模型名称目前统一映射至 Agnes 模型，不代表实际调用相应 GPT 模型。
- 项目、空间、插件目录、偏好和用量展示等原型界面；插件目录不代表真实连接，用量图是演示数据，不是账单。
- 当前没有云端账号、跨设备同步、真实支付、项目文件执行或电脑操控能力。服务端个人认证和云端数据隔离属于规划，尚未实现。
- 当前网关共用服务访问凭证，不适合直接作为开放注册的公网多用户服务。

## 本地运行

需要 Node.js 24 和 npm。首次安装：

```sh
npm ci
cp .env.example .env
```

在本机 `.env` 填写自己的 `AGNES_API_KEY`，生成至少 32 位随机服务凭证，并将 `STUDIO_GATEWAY_TOKEN` 与 `CODEX_STUDIO_AI_TOKEN` 设为相同值。不要提交或分享填写后的文件。

分别在两个终端运行：

```sh
npm run ai:server
```

```sh
npm run build
npm start
```

开发界面可使用 `npm run dev`，模型网关仍需单独启动。详细接口和限制见 [server/README.md](server/README.md)。远程模型地址必须使用 HTTPS。

## 检查

```sh
npm test
npm run build
```

自动化测试使用注入上游，不证明真实模型、服务额度或远程部署可用。需要自行配置供应商服务。
